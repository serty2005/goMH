# Правила для понимания контекста проекта goMH

## Описание проекта
Проект goMH представляет собой мультитул для техподдержки систем iiko и Syrve. Он предоставляет набор инструментов и модулей для автоматизации задач, управления конфигурациями, взаимодействия с сервисами и обеспечения удобного пользовательского интерфейса.

## Основные правила пользователя
- **Только русский язык**: Все коммуникации и документация ведутся исключительно на русском языке.
- **Никаких домыслов**: Все утверждения и изменения основываются только на предоставленных данных и фактах, без предположений.
- **Пошаговая работа**: Задачи выполняются последовательно, с подтверждением каждого шага.
- **Планирование объема ответа**: Ответы структурированы и ограничены необходимым объемом информации.
- **Формат ответа с конкретными правками**: Ответы включают точные описания изменений и правок.
- **Актуальные комментарии**: Код и документация содержат актуальные и полезные комментарии.

## Ключевые аспекты структуры проекта
- **main.go**: Основной файл приложения, точка входа в программу.
- **core/types.go**: Определения основных типов данных и структур, используемых в проекте.
- **modules/**: Директория с модулями для специфических функций:
  - **iiko/**: Модуль для работы с системой iiko.
  - **regime/**: Модуль для управления режимами работы.
  - **serviceutils/**: Утилиты для работы с сервисами.
  - И другие модули (dto, frpc, iikoplugins, remoteaccess, utm, vcomcaster).
- **winutils/**: Утилиты для работы с Windows.
- **tui/**: Текстовый пользовательский интерфейс (Terminal User Interface), включая меню и вывод.
