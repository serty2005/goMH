# goMH - Мультитул для технической поддержки

**goMH** - это специализированный инструмент для технической поддержки систем iiko и Syrve. Программа предоставляет удобный интерфейс для автоматизации рутинных задач, установки программного обеспечения и диагностики систем в среде Windows.

## Назначение проекта

goMH создан для упрощения работы технических специалистов при обслуживании систем автоматизации ресторанов и торговли. Программа объединяет в себе множество инструментов, которые обычно выполняются вручную или с помощью различных скриптов.

## Основные возможности

- **Автоматизированная установка ПО**: Установка продуктов iiko, модулей ЕГАИС, средств удаленного доступа.
- **Работа с обновлениями**: Автоматический поиск и установка патчей для iiko.
- **Диагностика и мониторинг**: Сбор логов, очистка временных файлов, мониторинг логов в реальном времени (`tail -f`).
- **Настройка оборудования**: Установка драйверов для фискального оборудования (Атол, Штрих-М, Poscenter) и виртуальных COM-портов для сканеров ШК.
- **Сетевая инфраструктура**: Настройка проброса портов, утилит для удаленного доступа, агента для сбора информации о системе.

## Требования к системе

- **Операционная система**: Windows 10/11.
- **Права доступа**: Запуск от имени администратора обязателен.
- **Сетевые возможности**: Доступ к интернету для загрузки дистрибутивов и конфигурации.

# Модули программы

## 1. iiko (Front, Back, Card)

Модуль для установки продуктов системы iiko - ведущей платформы автоматизации ресторанов и торговли в России.

### Особенности реализации

- **Автоматическое сканирование FTP**: Поиск доступных версий продуктов на FTP-сервере.
- **Интеллектуальное меню**: Динамическое формирование списка доступных компонентов.
- **Система патчинга**: Автоматический поиск и применение патчей для iikoFront после установки.
- **Логирование установки**: Подробное протоколирование процесса установки.

### Управление плагинами iikoFront

Модуль поддерживает автоматическое управление плагинами после установки iikoFront.

#### Параметры конфигурации (`iiko_config`)

- **`excluded_plugins`**: Список имен плагинов, которые будут исключены из всех операций.
- **`auto_update_plugins`**: Список фрагментов имен плагинов для автоматического обновления после установки iikoFront.

#### Логика автообновления

1. Определяется версия установленного iikoFront.
2. Загружается манифест плагинов с сервера.
3. Выбираются плагины для обновления, если их имя содержит одно из значений в `auto_update_plugins`.
4. Для каждого плагина находится последняя совместимая версия.
5. Выполняется обновление плагина с созданием резервной копии и сохранением `.config` файла.

## 2. Regime (Локальный модуль ЧестныйЗнак)

Модуль для установки и обновления системы Regime - локального компонента для работы с системой ЧестныйЗнак.

### Особенности реализации

- **Автоматическая проверка .NET Framework 4.8**: Установка недостающего компонента при необходимости.
- **Режим переустановки**: Обнаружение существующей установки и предложение обновления.
- **Логирование**: Подробное протоколирование процесса установки.

## 3. Утилиты обслуживания (ServiceUtils)

Комплексный модуль для диагностики и обслуживания рабочих станций.

### Доступные утилиты

- **Очистка временных файлов**: Автоматизированная очистка по путям и шаблонам, указанным в `MaintenanceConfig.TempPaths`.
- **Сборщик логов в архив**: Интеллектуальный сборщик логов за указанный период с поддержкой вложенных архивов (ZIP, GZIP, 7Z).
- **Просмотр логов в реальном времени**: Мониторинг лог-файлов (`tail -f`) с автоматическим поиском актуальных логов за день.
- **Патчи iikoFront**: Автономная система применения патчей с созданием и восстановлением бэкапов.
- **OrderCheck**: Инструмент для диагностики БД iikoFront и Алкоплагина.
- **FrontTools**: Набор инструментов для проверок iikoFront с автоматическим выбором версии под тип БД (DB/SDF).

## 4. Драйверы фискальных регистраторов (FiscalDrivers)

Модуль для централизованной установки драйверов фискального оборудования с выбором через подменю.

### Доступные драйверы

- **Драйверы АТОЛ**: Стандартная установка ДТО.
- **Драйверы Ритейл-\* (Poscenter)**: Установка с предварительной очисткой.
- **Драйверы Штрих/Элвес-\* (kktlab)**: Установка с предварительной очисткой.

### Особенности реализации

- **Интеллектуальная очистка**: Для драйверов Poscenter и kktlab модуль автоматически ищет предыдущие установки в стандартных директориях (`C:\Program Files (x86)\Poscenter`, `C:\Program Files (x86)\kktlab`, `C:\Program Files (x86)\SHTRIH-M\*`).
- **Надежное удаление**: Найденные старые версии удаляются в тихом режиме перед установкой нового драйвера.
- **Гибкая настройка**: Каждый драйвер и его параметры установки настраиваются в секции `fiscal_drivers_config` в файле конфигурации.

## 5. FRPC (Fast Reverse Proxy Client)

Модуль для настройки безопасного проброса портов через защищенный туннель.

### Особенности реализации

- **Автоматическая настройка NSSM**: Установка и настройка службы Windows.
- **Интеллектуальный выбор портов**: Автоматический поиск свободных портов на FRPS-сервере.
- **Управление службой**: Автоматический запуск и настройка автозапуска.
- **Настройка сервера в `frpc_config`**: Отдельный раздел для настройки своего FRPS-сервера.

## 6. Средства удаленного доступа

Комплексный модуль для установки различных решений удаленного доступа.

### Доступные компоненты

- **TeamViewer**: Установка кастомного Host-клиента с автоматическим поиском актуальной версии через API.
- **LiteManager**: Профессиональное решение для удаленного администрирования.
- **Getad Agent**: Специализированное решение для сбора информации о рабочей станции.

## 7. УТМ (ЕГАИС)

Модуль для установки Универсального Транспортного Модуля для работы с системой ЕГАИС.

## 8. [VComCaster](https://github.com/symp1ex/VComCaster)

Специализированный модуль для зеркалирования вывода сканеров штрих-кодов через виртуальные COM-порты.

### Особенности реализации

- **Автоматическое создание виртуальных портов**: Установка и настройка com0com.
- **Интеллектуальное определение устройств**: Автоматический поиск USB-COM сканеров и предложение пользователю выбрать нужный.
- **Интеграция с iiko**: Автоматическое обновление конфигурации портов в `config.xml` iiko.
- **Настройка автозапуска** через планировщик задач Windows.

# Инструкции по использованию

## Запуск программы

1.  **Права администратора**: Программа обязательно должна запускаться от имени администратора.
2.  **Конфигурация**: При первом запуске автоматически загружается файл конфигурации с удаленного сервера. Чтобы использовать свою конфигурацию, положите файл `config.json` рядом с `goMH.exe`.
3.  **Главное меню**: После запуска отображается меню с доступными модулями.

## Конфигурация

Программа использует JSON-конфигурацию для настройки. По умолчанию файл загружается с URL, указанного в `main.go`.

### FiscalDriversConfig

Раздел конфигурации для модуля драйверов. Представляет собой массив объектов.

```json
"fiscal_drivers_config": [
  {
    "id": "atol",
    "menu_text": "Драйверы АТОЛ",
    "asset_id": "DTO_Installer",
    "install_args": "/S"
  },
  {
    "id": "poscenter",
    "menu_text": "Драйверы Ритейл-* (poscenter)",
    "asset_id": "Poscenter_Driver_x32",
    "install_args": "/COMPONENTS=\"usbdrv,kktproxy\" /VERYSILENT /TASKS=\"desktopicon\""
  }
]
```

# Для разработчиков

## Сборка проекта

### Требования

- Go 1.23 или выше
- Git для управления зависимостями

### Команды сборки

```bash
# Клонирование проекта
git clone https://github.com/serty2005/goMH.git
cd goMH

# Загрузка зависимостей
go mod download

# Быстрая сборка для разработки
go build -o goMH.exe .

# Сборка для релиза (с оптимизацией размера)
go build -ldflags="-s -w" -o goMH.exe
```

### Структура проекта

```
goMH/
├── main.go                # Точка входа в приложение
├── core/
│   └── types.go           # Определения интерфейсов и базовых структур
├── modules/               # Реализация модулей
│   ├── fiscal-drivers/    # Драйверы ФР (Атол, Штрих, Poscenter)
│   ├── frpc/              # Fast Reverse Proxy Client
│   ├── iiko/              # Продукты iiko + система патчинга
│   ├── iiko-plugins/      # Управление плагинами iiko
│   ├── regime/            # Локальный модуль ЧестныйЗнак
│   ├── remoteaccess/      # Средства удаленного доступа
│   ├── serviceutils/      # Утилиты обслуживания
│   ├── utm/               # УТМ для ЕГАИС
│   └── vcomcaster/        # Работа со сканерами
├── assetmgr/              # Менеджер ресурсов и загрузок
├── config/                # Конфигурационные структуры
├── dependencies/          # Управление внешними зависимостями (7-Zip)
├── tui/                   # Интерфейс пользователя
└── winutils/              # Утилиты для работы с Windows
```

## Расширение функциональности

Для добавления нового модуля необходимо:
1.  Создать директорию в `modules/`.
2.  Реализовать структуру `Module`, удовлетворяющую интерфейсу `core.Installer`.
3.  Зарегистрировать модуль в `main.go`.
4.  При необходимости добавить секцию в `config/config.go` и в `config.json`.
