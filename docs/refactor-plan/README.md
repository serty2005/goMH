# План Полировки

Этот каталог теперь хранит не поэтапный roadmap, а один актуальный пакет для следующей сессии полировки проекта после завершенного рефакторинга.

## Текущий контекст

- Целевая версия языка: `Go 1.25.1`.
- Основной рефакторинг уже выполнен.
- Требуется не новая архитектурная перестройка, а доведение текущего состояния до качественного и предсказуемого результата.
- Функциональность терять нельзя.

## Зафиксированные ограничения

- Логи не используются как источник состояния или бизнес-логики.
- Общий лог утилиты должен продолжать существовать.
- Отключение файлового логирования должно означать только отключение записи в файл, а не выключение всего логгирования.
- Отмена задач пока поддерживается только на этапе скачивания с удалением недокачанного файла.
- Для остальных задач отмена не реализуется до появления полноценного механизма компенсации по паттерну саги.
- GUI-режим пока считается тестовым фундаментом и не является целевой пользовательской поверхностью текущего этапа.

## Что считается успешным результатом

- Код приведен к аккуратному и внутренне согласованному состоянию.
- Убраны оставшиеся архитектурные шероховатости без новой большой перестройки.
- Границы по отмене задач честно отражены в runtime и UX.
- Текущее состояние GUI не мешает развитию, но не выдается за полностью готовый режим.
- `go test ./...` и `go vet ./...` проходят.
