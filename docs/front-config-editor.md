# Редактор config.xml iikoFront / SyrveFront

Откройте **iiko / Syrve → Редактор конфига** в меню выбора продукта.
Редактор проверяет два файла текущего пользователя:

- `%APPDATA%\iiko\CashServer\config.xml`
- `%APPDATA%\Syrve\CashServer\config.xml`

Если существуют оба файла, открывается файл с более поздним временем изменения.
При одинаковом времени выбирается iiko. Путь и время изменения видны над списком.
Если свежий файл повреждён или недоступен, редактор сообщает об ошибке, не переключаясь
молча на старый. При запуске goMH под другим пользователем его `%APPDATA%` может
отличаться от профиля, под которым работает Front.

Перед изменением закройте Front. После сохранения запустите его заново для применения
параметров. Редактор сам не останавливает и не запускает процессы.

## Управление

В начале списка расположены `AllowHandCardRoll`, `ShowMinimizeButton` и `serverUrl`,
если они присутствуют в XML. Для них отображаются краткие пояснения из документации.
Остальные параметры сохраняют порядок из файла. Вложенные параметры показаны с путём,
например `fastMenuConfig/commonProductPanelWidth`, повторяющиеся теги — с номерами,
например `allowedParsers[1]` и `allowedParsers[2]`.

| Клавиша | Действие |
| --- | --- |
| ↑ / ↓, Tab / Shift+Tab | Выбрать параметр |
| PgUp / PgDn, Home / End | Перейти по списку |
| Ввод текста в списке | Искать по имени, пути или пояснению без учёта регистра |
| Пробел | Переключить выбранное значение true / false |
| Enter | Переключить флаг или открыть строковое поле |
| Enter в поле | Применить введённое значение к черновику |
| Esc в поле | Отменить текущий ввод |
| Ctrl+V в поле | Вставить текст из буфера обмена |
| Ctrl+N | Переключить «не задано» для параметра с атрибутом `xsi:nil` |
| Ctrl+R | Вернуть исходное значение выбранного параметра |
| Ctrl+S | Сохранить все изменения, включая скрытые поиском, и закрыть редактор |
| Esc в списке | Очистить поиск, затем выйти из редактора |
| Ctrl+C | Выйти из редактора |

Звёздочка отмечает изменённые параметры. При выходе с правками нужно выбрать
«Выйти без сохранения» либо продолжить редактирование. По умолчанию выбрано продолжение.
Пустая строка отличается от `xsi:nil`: ввод значения удаляет этот атрибут,
а переключение в «не задано» сохраняет атрибут и очищает текст элемента.

## Сохранение

Редактируются существующие конечные элементы XML. Имена тегов и атрибуты,
вложенность, повторяющиеся элементы, комментарии и неизвестные параметры сохраняются.
Добавления и удаления параметров через интерфейс нет. Текстовые значения экранируются
как XML; пробелы по краям не обрезаются. Поддерживаются UTF-8 (в том числе с BOM)
и UTF-16 с BOM. После правок сериализация может изменить оформление XML, например
запись пустых тегов. Без изменений файл не перезаписывается.

При сохранении:

1. Проверяется, что содержимое исходного файла совпадает со снимком при открытии.
2. Рядом создаётся отдельная копия `config.xml.gomh-<уникальный суффикс>.bak` с исходными байтами.
3. Изменённый XML записывается во временный файл в той же папке.
4. После повторной проверки исходного файла новая версия заменяет его.

Если файл изменился другой программой, сохранение отклоняется: откройте редактор
заново и повторите правки. Проверка не заменяет закрытие Front перед редактированием.
При ошибке записи исходник не обрезается; ошибка отображается пользователю.
Резервные копии предыдущих сохранений не перезаписываются.

Редактор выполняется сразу, без добавления в очередь установки. Рабочий `config.json`
goMH не используется для хранения параметров Front и не изменяется редактором.
